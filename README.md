# Werkbank

Werkzeug-Set fürs Heimwerken: Wasserwaage, Lot, Kompass, Neigungsmesser.
Ohne Werbung, ohne Konto, ohne Tracking, läuft offline.

**Installieren:** https://kimaeleon1-glitch.github.io/werkbank-app/ auf dem Handy in Chrome öffnen, warten bis die
Startseite da ist, dann im Chrome-Menü „App installieren“ wählen.

Dieses Repo enthält nur die ausgelieferten App-Dateien (Version 1.2.1).
